    Installation

    • Install locations Steam library, Wine runtime and Wine setup.
    • Check for launcher updates Asks GitHub for new versions when the launcher opens. Nothing else is sent.

    Debug

    • Performance overlay FPS, frame time and GPU memory in the game's corner.
    • Logs Export puts everything a bug report needs into one file on your desktop.
    • Force close Ends Runehaven immediately if it hangs. Unsaved progress is lost.

    Uninstall Runehaven Mac Launcher?

    The launcher's settings are removed and the app moves to the Trash. What else should go?

    • Wine runtimeWineCX, DXMT, libraries and downloads
    • Wine setupYour save games are packed onto the desktop first.
    • LogsOnly needed for bug reports.
    • Runehaven itselfUninstalled through Steam.
