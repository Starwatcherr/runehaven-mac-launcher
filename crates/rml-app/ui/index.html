    Settings

    Display

    • Full screen Runehaven gets its own desktop, like the green window button.
    • Retina Sharp picture at the display's full resolution, more work for the GPU.
    • Window size Used when full screen is off.

    Debug

    • Performance overlay FPS, frame time and GPU memory in the game's corner.
    • Logs Export puts everything a bug report needs into one file on your desktop.
    • Force close Ends Runehaven immediately if it hangs. Unsaved progress is lost.

    Changes apply the next time Runehaven starts.
